# Characterization of Simple Electronic Filters Using Physics-Informed Neural Networks

## Overview
This project explores the use of **Physics-Informed Neural Networks (PINNs)** for the characterization of simple electronic filters. By embedding physical laws directly into the learning process, PINNs reduce dependency on large datasets while maintaining accurate and efficient predictions.

This final bachelor year project aims to demonstrate how combining machine learning with domain knowledge from physics and electronics can lead to more robust and data-efficient models.

## Objectives
- Understand the principles of Physics-Informed Neural Networks  
- Model simple electronic filters using governing physical equations  
- Reduce data dependency through physics-based constraints  
- Compare PINN-based approaches with traditional data-driven models  
- Analyze model performance in terms of accuracy and efficiency
